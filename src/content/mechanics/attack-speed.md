# Attack Speed

In **Idle Guild Master Modded (IGM+)**, Attack Speed determines how many strikes an adventurer or enemy performs each combat round.

## Core Rules

* **Baseline:** All entities start with a baseline of **100% Attack Speed** (1 standard strike per round).
* **Multi-Strike Threshold:** Every **+100% Attack Speed** guarantees **+1 extra strike** per round (e.g., 200% Attack Speed guarantees 2 strikes every turn).
* **Fractional Strike Chance:** Fractional Attack Speed grants an exact percentage chance to perform an additional strike:
  * **+50% Attack Speed:** 50% chance for a 2nd strike each round.
  * **+75% Attack Speed:** 75% chance for a 2nd strike each round.
  * **+120% Attack Speed:** 1 guaranteed extra strike + 20% chance for a 3rd strike each round.

## Synergies & Status Stacking

* **On-Hit & Status Procs:** Each extra strike triggers on-hit effects, equipment procs, and status afflictions (such as Bleed, Burn, or Freeze).
* **Deadly Finesse Archetype:** High-dexterity rogue specializations trade off Basic Attack Amplification in exchange for massive Attack Speed (+50% to +100%), allowing classes like Spirit Engraver to reliably apply high Bleed stacks every single turn.
