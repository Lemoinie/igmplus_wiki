# Skill Amp

In **Idle Guild Master Modded (IGM+)**, **Skill Amp** is the specialized multiplier governing the power of active class skills and spells.

## Core Rules

* **Baseline:** All entities start at a baseline of **100% (1.0×)** Skill Amp.
* **Scope:** Exclusively scales:
  * Active skill strikes and spell bursts executed by adventurers and enemies.
  * Active skill healing and area restoration spells.
* **Separation from Basic Attacks:** Does **not** modify standard round weapon swings (which use Basic Atk Amp).
* **Inspection Dialog:** Inspectable on Page 3 of the hero and enemy detail dialogs.

## Formula

**Skill Damage** = **Skill Base Damage** × **Damage Dealt Modifier** × **Skill Amp**

## Synergies & Equipment

* **Aether Resonance (Burst Mage Line):** The Apprentice single-target burst line (Arcanist through Singularity Magus) features the Aether Resonance passive, providing **+10% up to +70% Skill Amp** (+10% per tier) along with matching enemy defense penetration.
* **Scarlet Sigil:** Grants a flat **+20% Skill Amp**, greatly elevating high-multiplier active skill rotations.
* **Skill Independence:** Characters utilizing high attack-speed setups (like Spirit Engraver) retain **100% full skill damage** via Skill Amp even when Basic Atk Amp is reduced.
