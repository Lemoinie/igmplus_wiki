# Dungeons

Dungeons are room-crawling expeditions: each room search can trigger a combat
roll, an event, or nothing at all. The tables below show each dungeon's overall
encounter chance per room and the relative share of every enemy in its combat
pool (percentages sum to the encounter chance).

::: tip Reading the numbers
- **Encounter chance** — probability that searching a room starts a fight.
- **Share of encounters** — if a fight starts, how likely each enemy/group is.
- **Loot references** — every item the dungeon's code can grant (room finds,
  event rewards, merchant stock).
:::

Route guides, boss mechanics, and raid strategies are detailed in the [Raids](./raids) section.
