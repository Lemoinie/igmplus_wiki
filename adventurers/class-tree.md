# Class Tree

Every adventurer starts at a **T1 base class** (Apprentice, Footman, Archer,
Rogue, Outlander, …) and promotes through branch choices up to the mod's
**T9 pinnacle** classes. Tiers on this wiki are computed automatically from the
promotion graph (`nextClasses` in each class file) — brand-new mod classes show
up without any manual bookkeeping.
